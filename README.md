# IT Help Desk Ticket Analysis & Support Performance Dashboard

## 📌 Project Overview

The **IT Help Desk Ticket Analysis & Support Performance Dashboard** is a data analytics and business intelligence project designed to analyze IT support tickets and identify trends, recurring technical issues, resolution performance, workload, SLA compliance, and customer satisfaction.

Organizations generate a large number of IT support tickets every day. Manually monitoring ticket volume, issue categories, priority, resolution time, and support-team performance makes it difficult to identify recurring problems and improve IT service efficiency.

This project uses **SQL, Excel, and Power BI** to transform IT help desk ticket data into meaningful insights and an interactive dashboard for data-driven decision-making.

---

## 🎯 Problem Statement

Organizations generate a large number of IT support tickets every day, but manually monitoring ticket volume, issue categories, resolution time, priority, and support-team performance makes it difficult to identify recurring problems and improve IT service efficiency.

This project aims to analyze IT help desk ticket data using **SQL, Excel, and Power BI** to identify trends, measure key performance indicators, and provide actionable insights for better IT support management.

---

## 🎯 Project Objectives

- Analyze overall IT support ticket volume.
- Identify the most common IT issue categories.
- Analyze ticket priority levels.
- Measure average ticket resolution time.
- Compare open, resolved, and closed tickets.
- Evaluate support-agent workload and performance.
- Measure SLA compliance.
- Identify departments generating the highest number of tickets.
- Analyze customer satisfaction.
- Build an interactive Power BI dashboard for management decision-making.

---

## 📊 Key Business Questions

1. How many IT support tickets are generated?
2. Which IT issue categories generate the most tickets?
3. Which departments raise the most support requests?
4. How many critical and high-priority tickets are there?
5. What is the average resolution time?
6. Which categories take the longest to resolve?
7. How many tickets are currently open?
8. Which support agents handle the highest workload?
9. What percentage of tickets meet the SLA?
10. How satisfied are users with IT support?
11. What trends can be identified over time?
12. What actions can improve IT support efficiency?
